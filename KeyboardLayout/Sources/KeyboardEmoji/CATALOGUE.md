Fully qualified entries only, in Unicode recommended order within each category. People and smileys are combined. Skin-tone sequences are grouped with their base glyph (mixed-tone sequences by base label). Entries retain their Emoji version for OS compatibility. Apple renders glyphs using the system emoji font; no Apple artwork is bundled. Unicode license is included in the resource bundle.
